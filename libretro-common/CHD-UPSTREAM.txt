Existing file I/O/thread/atomic facilities remain owned by this core.

This is codec groundwork, not a mounted CHD backend. These sources are
compiled by libretro/tests/test-chd-codecs.py, not the core Makefile yet.
Enable all four HAVE_RCHD_{DEFLATE,LZMA,FLAC,ZSTD} when integrating them.
The existing deflate, CRC32, CPU-feature and compatibility headers are reused.

The pinned API accepts pipeline depth one only. Borrowed input must remain
valid until the read step has consumed it. A step bounds decoding by hunk,
not host wall-clock time: run file access and decoding on their owned worker,
not on retro_run. Do not add a guest-visible wait for a worker completion.
ATAPI PIO's mid-phase synchronous refill must be replaced before enabling
compressed media, while preserving the announced byte count and DRQ burst.
